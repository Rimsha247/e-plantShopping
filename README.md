# Paradise Nursery

## Project Description

Paradise Nursery is a React-based online houseplant shopping application.
The application allows users to browse different categories of houseplants,
add plants to a shopping cart, change quantities, and remove items from the
cart.

## Features

- Landing page with Paradise Nursery branding
- Background image
- Company description
- Get Started button
- Product listing page
- Three plant categories
- Multiple houseplants with images, names, and prices
- Add to Cart functionality
- Dynamic shopping cart quantity
- Redux state management
- Increase and decrease cart quantities
- Delete items from the cart
- Total plant count
- Total cart cost
- Checkout button
- Continue Shopping button
- Responsive design

## Technologies Used

- React
- Vite
- Redux Toolkit
- React Redux
- React Router
- CSS
- GitHub Pages

## Plant Categories

1. Indoor Plants
2. Succulents
3. Flowering Plants
